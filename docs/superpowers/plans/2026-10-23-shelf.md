# Parametric Wall Shelf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up the tridi repo and a command that generates print-ready files for any variant of the parametric wall shelf.

**Architecture:** Plain Python inside the pixi environment imports FreeCAD as a library. `import tridi` puts FreeCAD's lib directory on `sys.path`, so there is no `freecadcmd` and no environment-variable argument passing. A shared package `src/tridi/` provides parameters, printers, geometry features and export. The shelf project (`projects/shelf/`) splits into:
- a pure-Python **layout**: positions of brackets, holes, notches, windows and hexes, plus every collision check;
- FreeCAD **geometry** built from that layout;
- a `build()` entry point that `run.py` calls.

**Tech Stack:** pixi (conda-forge), FreeCAD 1.1 (`Part`, `Mesh`, `MeshPart`) as a Python library, Python 3.12, pytest, `tomllib`.

**Spec:** `docs/superpowers/specs/2026-10-23-shelf-design.md`. The reference for the approved look is `docs/superpowers/specs/2026-10-23-shelf-spike.py`; match its proportions.

## Global Constraints

- FreeCAD `1.1.*`, Python `3.12.*`, conda-forge, pixi. `pixi.toml` platforms: `linux-64`, `osx-arm64`, `win-64`. Only Linux is tested.
- No personal information in tracked files: no home paths, room or house details, or the user's own sizes. The author's name may appear only in `LICENSE` (already committed). Personal presets go in a gitignored `local.toml`.
- Units are mm. Use coordinates: X along the wall (width), Y out from the wall (y=0 is the wall), Z up, slab top at z=0.
- Every exported part is a single valid solid that prints without support material.
- The build refuses (exit code 2, one clear message, no traceback, **no files written**) on:
  - an out-of-range parameter;
  - an unsupported combination;
  - a geometry collision;
  - a part too big for the printer.
- PLA density for weight estimates: 1.24 g/cm³.
- Code style: small focused modules, type hints, docstrings only where the why isn't obvious. Every source file, README and committed preset is in English.

## Review Focus

1. **Small or crowded shelves** (e.g. `--width 60`, or `--width 120 --notch back-left --notch back@60`). Expected: a refusal naming the colliding things, never an invalid solid or a crash. Tested in Task 7 (`test_narrow_shelf_refuses_cleanly`).
2. **Shelf too big for the printer** (`--width 300` on the MK3S). Expected: refused before any file is written. Tested in Task 5 (`test_too_big_writes_nothing`) and Task 12 (`test_cli_too_big_exit_code`).
3. **A typo in `local.toml` or on the command line** (`widht = 300`, `--preset livingroom` when no such preset exists). Expected: a refusal that lists the valid names. Tested in Task 2 (`test_unknown_key_lists_valid`, `test_unknown_preset_lists_available`).
4. **Every option turned on at once** (honeycomb + cleat + notches + lip + clips, supports above). Expected: one valid solid per part. Tested in Task 12 (`test_everything_on`).
5. **A boolean or fillet operation that silently yields several solids or an invalid shape.** Expected: the build stops with a clear message. Tested in Task 8 (`test_body_single_valid_solid` helper `assert_single_solid`, used by every geometry test after it).

### Task 2: Parameters

**Files:**
- Create: `src/tridi/params.py`, `tests/test_params.py`

**Interfaces:**
- Produces:
  - `param(default, help: str, *, min: float | None = None, max: float | None = None, choices: tuple | None = None) -> dataclasses.Field`. Stores `help`, `min`, `max` and `choices` in the field metadata.
  - `class ParamError(ValueError)`.
  - `validate(obj) -> None`. Checks every field of a dataclass instance. `None` passes, meaning "auto". Message forms: `"width = 20 is below the minimum 40"`, `"supports = 'side' is not one of: below, above"`.
  - `load_presets(project_file: Path, local_file: Path, project: str) -> dict[str, dict]`.
    - `project_file` holds top-level tables `[<preset>]`. `local_file` holds `[<project>.<preset>]`.
    - Local presets override same-named ones.
    - A missing file means `{}`.
  - `resolve(cls, presets: dict[str, dict], preset: str | None, overrides: dict) -> instance`.
    - Precedence: defaults < preset < overrides. Lists in the TOML become tuples.
    - Unknown key → `ParamError("unknown parameter 'widht'; valid: ...")`.
    - Unknown preset → `ParamError("unknown preset 'x'; available: a, b")`.
    - Calls `validate`.
  - `add_cli_arguments(cls, parser: argparse.ArgumentParser) -> None`. One `--kebab-case` option per field, `default=argparse.SUPPRESS`, help taken from the metadata.
    - `bool` fields become `--x/--no-x` (`BooleanOptionalAction`).
    - `tuple[str, ...]` fields use `action="append"`. The option name is singular when the field name ends in `s`: `notches` → `--notch`.
    - Optional numeric fields also accept the string `auto`, which maps to `None`.
  - `cli_overrides(cls, ns: argparse.Namespace) -> dict`. Returns only the options given, converted to field types.
  - `variant_name(preset: str | None, overrides: dict) -> str`. Example: `"default_width-300_notches-back-left+back@60"`. Override keys are sorted and the result matches `[a-z0-9_.+@-]+`.
  - Annotation types read with `typing.get_type_hints`: `float`, `int`, `str`, `bool`, `tuple[str, ...]`, `float | None`, `int | None`.

### Task 4: Geometry features

**Files:**
- Create: `src/tridi/features.py`, `tests/test_features.py`

**Interfaces:**
- Consumes: `import tridi` (bootstrap).
- Produces: functions returning `Part.Shape` cutters or solids, all in mm.
  - `countersunk_hole(at: Vector, axis: Vector, depth: float, hole_d: float, head_d: float, teardrop_up: Vector | None = None) -> Part.Shape`.
    - `at` is a point on the face where the head sits, and `axis` is that face's outward normal.
    - Shape: a shaft of `hole_d` from 1 mm outside the face to `depth + 1` mm into the material, a 90° cone from `hole_d` to `head_d` ending at the face, and a 1 mm cylinder of `head_d` outside the face.
    - With `teardrop_up` set, the shaft cross-section becomes a teardrop pointing that way.
  - `teardrop_hole(at: Vector, axis: Vector, length: float, d: float, up: Vector) -> Part.Shape`. A circle of diameter `d` plus a 45° point toward `up`. The point is cut flat at distance `d/2` from the centre (a flat-topped teardrop).
  - `rounded_slot(p0: tuple[float, float], p1: tuple[float, float], width: float, z0: float, height: float) -> Part.Shape`. A stadium shape (semicircular ends) along p0→p1 in XY, extruded along +Z.
  - `rounded_rect(x0: float, y0: float, x1: float, y1: float, r: float, z0: float, height: float) -> Part.Shape`. A rectangle with corner radius `r` in XY, extruded along +Z.
  - `hex_prisms(centres: list[tuple[float, float]], across_flats: float, z0: float, height: float, vertex_axis: str) -> Part.Shape`. A compound of hexagonal prisms along +Z. `vertex_axis` is `"x"` or `"y"`: the in-plane axis that a vertex points along.
  - `fuse_all(shapes: list[Part.Shape]) -> Part.Shape`. A single fuse followed by `removeSplitter()`.
  - `assert_single_solid(shape: Part.Shape, what: str) -> Part.Shape`. Raises `GeometryError(f"{what}: geometry kernel produced {n} solids / an invalid shape")` unless `shape.isValid()` and there is exactly one solid. Returns that solid.
  - `class GeometryError(RuntimeError)`.

### Task 5: Export

**Interfaces:**
- Consumes: `Printer` and `check_fit` (Task 3), `assert_single_solid` (Task 4).
- Produces:
  - `@dataclass class PrintPart: name: str; shape: Part.Shape; rotation: FreeCAD.Rotation; count: int = 1; orientation: str = ""`. `shape` is in use coordinates; `orientation` is a human label for the summary.
  - `to_bed(shape: Part.Shape, rotation: FreeCAD.Rotation) -> Part.Shape`. Rotated, then translated so the bounding box minimum is (0, 0, 0).
  - `export(parts: list[PrintPart], out_dir: Path, *, title: str, params: dict, printer: Printer, notes: list[str]) -> Path`.
    - First, check every part with `check_fit`. If any part fails, raise before writing anything. That includes not creating `out_dir`.

      - `<name>.stl` and `<name>.3mf` per part, in print orientation, meshed with `MeshPart.meshFromShape(Shape=..., LinearDeflection=0.05, AngularDeflection=0.2618)`. When `count > 1`, the copies are laid out in rows along X with 4 mm gaps, wrapping before the printer's X.
      - `assembly.step`: all parts once each, in use coordinates.
      - `<title>.FCStd`: one Part feature per part, in use coordinates.
      - `summary.txt`.
    - Returns the summary path.
  - `summary.txt` format, one item per line:
    - `title`, then `printer: <name> (<x> × <y> × <z> mm)`.
    - `parameters:` followed by `  key = value` lines, in sorted order. Tuples are joined with `, ` and `None` prints as `auto`.
    - Per part: `<name> ×<count>: <volume cm³, 1 decimal> cm³, ~<weight g, 0 decimals> g each (solid), print size <x> × <y> × <z> mm, <orientation>`.
    - `total: ~<g> g`.
    - `notes:` lines.

    - Size: `width` 200 [40, 1000]; `depth` 100 [30, 400]; `slab_thickness` 4 [2, 12]; `plate_thickness` 4 [2, 12].
    - Brackets:
      - `supports` "below" (`below`/`above`).

      - `mount` "screws" (`screws`/`keyhole`/`cleat`/`adhesive`).

      - `plate_style` "full" (`full`/`windowed`/`pads`).
      - `surface` "solid" (`solid`/`honeycomb`); `hex_cell` 10 [5, 40]; `hex_wall` 2 [1, 10]; `solid_rim` 8 [4, 30].

      - `notches: tuple[str, ...]` (); `notch_width` 14 [6, 40]; `corner_notch_r` 15 [6, 40].

      - `orientation` "flat" (`flat`/`side`).

  - `class LayoutError(ValueError)`.
  - `@dataclass(frozen=True) class Notch: label: str; kind: str; x0: float; x1: float; r: float`.
    - `kind` is `"corner"` or `"slot"`.
    - `x0`/`x1` is the span along X.
    - `r` is the corner radius (`wall_offset + corner_notch_r`) or half of `notch_width`.
  - `@dataclass(frozen=True) class Layout`:
    - `slab_z: tuple[float, float]`, `plate_z: tuple[float, float]`;
    - `brackets: tuple[float, ...]` (centre x);
    - `holes: tuple[tuple[float, float], ...]` ((x, z) on the plate's front face; for keyholes, the screw's final position);
    - `pads: tuple[tuple[float, float], ...]` (x spans);
    - `windows: tuple[tuple[float, float, float, float], ...]` ((x0, z0, x1, z1));
    - `notches: tuple[Notch, ...]`;
    - `hexes: tuple[tuple[float, float], ...]` ((x, y) centres);
    - `hex_vertex_axis: str`;
    - `hook_height: float` (0 unless cleat).
  - `plan(p: ShelfParams) -> Layout`. Takes params already passed through `effective`. Raises `LayoutError`.
- Rules (values pinned from the spec and the spike). `W` is width, `t` is `bracket_thickness`, `hd` is `screw_head_d`.
  - **Slab and plate z.**
    - `slab_z = (-slab_thickness, 0)`.
    - Below: the plate runs from `-slab_thickness - bracket_height - (adhesive_extra if adhesive)` up to `strip_height` if `top_screws == "strip"` and the mount is screws or keyhole, else 0.
    - Above: the plate runs from `-slab_thickness` up to `bracket_height + (adhesive_extra if adhesive)`.
    - `hook_height = cleat_thickness + 6` for the cleat, else 0.
  - **Brackets.**
    - Auto count for below: `n = max(2, ceil((2W/3) / 160) + 1)`, evenly spread from `W/6` to `5W/6`.
    - Auto count for above: `n = max(2, ceil((W - t) / 160) + 1)`, evenly spread from `t/2` to `W - t/2`. A corner notch on an end moves that end bracket inward to `r + 2 + t/2` from that side.
    - An explicit `bracket_count` uses the same spans.
    - Brackets closer than `t + 10` centre to centre → `LayoutError` (`"too many brackets for this width"`).
  - **Holes.** Used for screws and keyhole; none for cleat or adhesive.
    - Rows for below: top row at `z = -slab_thickness - 10` (under) or `strip_height / 2` (strip); bottom row at `plate_bottom + 10`.
    - Rows for above: top row at `plate_top - 10`; bottom row at `z = 10`.
    - Columns for full and windowed plates: in each gap between adjacent brackets, the clear width is the gap minus `t` minus `2 × (hd/2 + 3)`. If the gap is ≥ 80, place columns at 1/3 and 2/3 of the gap; otherwise one column in the middle. A gap with clear width ≤ 0 gets no column.
    - Columns for pads: one per bracket, at `centre + s · (t/2 + hd/2 + 4)`, where `s` points toward the shelf centre (+1 when `centre ≤ W/2`).
    - Fewer than 2 columns in total → `LayoutError("no room for screw holes between the brackets; widen the shelf or use --mount cleat/adhesive")`.
  - **Pads.** Each spans `[centre - t/2 - 4, hole_x + hd/2 + 6]`, ordered low to high.
  - **Windows** (windowed plate only).
    - Spans: every gap between adjacent brackets, plus, for below, the two end spans outside the outer brackets.
    - Frame of 10: windows run from bracket face + 10 to the next face (or shelf end) − 10.
    - In z, the frame is 10 from the plate edges and 10 from the slab. Next to the hook, the frame is `hook_height + 4`.
    - Windows are trimmed to stay ≥ 10 away from every notch span. A window smaller than 20 × 20 is dropped.
    - The body (not the layout) keeps a disk of radius `hd/2 + 5` around every hole.
  - **Notches.**
    - Corner: left is `[0, r]`, right is `[W - r]`.
    - Slot: `[x - w/2, x + w/2]`. It must lie within `[0, W]`, otherwise `LayoutError`.
  - **Collisions** → `LayoutError`, with the format `"notch back@33 (26.0–40.0 mm) collides with bracket 1 (28.5–37.5 mm)"`. A notch span must not overlap:
    - any bracket span widened by 1 mm on each side;
    - any hole keep-out `[hx - hd/2 - 2, hx + hd/2 + 2]`;
    - any pad span;
    - another notch.
  - **Hexes** (honeycomb only).
    - The allowed region is x in `[solid_rim, W - solid_rim]`, y in `[wall_offset + plate_thickness + solid_rim, depth - solid_rim - (front_lip + 2 if front_lip else 0)]`.
    - Excluded: x within `[c - t/2 - 4, c + t/2 + 4]` of each bracket; a disk of radius `r + 6` around each corner notch's corner; and each slot's x-span ± 6 for y up to `wall_offset + plate_thickness + notch_width + 6`.
    - `hex_vertex_axis` is `"y"` for the flat orientation and `"x"` for side.
    - Grid: pitch `hex_cell + hex_wall` across the flats, row pitch `pitch · √3/2` with alternate rows offset by `pitch/2`, centred on the region.
    - A hex is kept only if its bounding box lies fully inside the allowed region and outside every exclusion.
