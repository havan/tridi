# Air Vent Flange Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `flange` project that builds print-ready air vent flanges for a drying box's side wall, in any combination of shape, fixing and mesh.

**Architecture:** Parameters and refusals live in `params.py`, pure maths in `layout.py` (no FreeCAD, so it's quick to test), and solids in `parts.py`. A stadium described by radius `r` and spine half-length `s` covers both shapes: round is `s = 0`. The shared exporter gains one small feature for slicer modifier parts.

**Tech Stack:** Python 3.12, FreeCAD 1.1 (`Part`, `MeshPart`), pytest, pixi.

**Spec:** `docs/superpowers/specs/2026-11-06-flange-design.md`

## Global Constraints

- Work only in `/hgst/work/github.com/havan/tridi-flange` on branch `feat/flange`. Another session is active in the main checkout, so never touch it. Run `pixi install` here once before the first test.
- Follow `projects/fanbox/` for module shape and `FanboxParams` conventions: `param(...)` with ranges, `None` for auto, `ParamError` for refusals, and a resolved copy reaching the geometry.
- Leave `projects/fanbox/` and `projects/shelf/` unchanged.
- No variant may need supports. Every printed part is one valid solid, checked with `assert_single_solid`.
- Default hardware: M4 countersunk hex-socket bolts, DIN 934 nuts (7 mm across flats, 3.2 mm high), 4.5 mm hole, 8 mm head, 0.5 mm sink. Head seat and nut pocket grow with the printer's `clearance`, as in `fanbox`.
- Use coordinates: z = 0 is the wall's outside face, +z points out of the box, and the wall is z ∈ [−wall_thickness, 0]. The slot's long side runs along x.

## Review Focus

1. A mesh hole too coarse for the opening, or bars covering all of it, leaves no holes. Expect a refusal, not a blocked vent. Test in Task 2.
2. A very fine mesh or very large opening would hang the build. Expect a refusal naming the cell count. Test in Task 2.
3. Mesh thickness equal to the outer piece's thickness (the "flat plug" from the spec) leaves no frame layer. Expect a valid part, not a crash. Test in Task 5.
4. A thick wall, such as 6 mm, or a seal changes the stack. Expect the collar, hub stop and bolt length to follow. Test in Task 2.
5. The modifier and outer piece load misaligned on a slicer's bed, which would apply the settings to the wrong region. Expect matching bed coordinates. Test in Task 5.

- [ ] **Step 4: Implement `layout.py`**

`layout.py` imports `FlangeParams` under `TYPE_CHECKING` only, so `params.py` can import it. Algorithms the signatures don't determine:

Rim bolts: on round, angles `90° + k·360°/n` at radius `r + rim/2`. On slot, walk the path at radius `ρ = r + rim/2`, total length `L = 4s + 2πρ`, starting at the `+x` apex with spacing `L/n`, so an even `n` is symmetric and has a bolt at each end.

Hubs: `x = (i + 0.5 − n/2)·(slot_length/n)`. Bars: round, rays at `90° + k·360°/bars` from `hub_d/2` to `r`; for `bars=2`, along ±x. Slot, one segment across at each hub, `(x, −r)` to `(x, r)`.

Cells, lattice centred on the origin, pitch `q = mesh_hole + mesh_rib`, rotated by `mesh_angle`:
- grid points `(i·q, j·q)`, cell area `mesh_hole²`, circumradius `mesh_hole·√½`
- honeycomb points `((i + (j mod 2)/2)·q, j·q·√3/2)`, area `mesh_hole²·√3/2`, circumradius `mesh_hole/√3`
- keep a cell when `spine_distance + circumradius + mesh_rib ≤ r`, and it's at least `circumradius + mesh_rib` from every hub's disk and at least that from every bar's edge

`mesh_cells` returns `[]` for `wire` and `slicer`. `open_area` is cell count × cell area for printed meshes and `area_after_bars` otherwise. `area_after_bars`: round subtracts the hub's disk and `bars · bar_width · (r − hub_d/2)`. Slot subtracts, per hub, the disk and `bar_width · (2r − hub_d)`. It equals `opening_area` for other fixings.

- [ ] **Step 5: Implement `params.py`**

Checks are one `_problems(p) -> list[str]`. Without `force`, `effective` raises `ParamError` joining them plus a `--force` hint. With it, each becomes a `forced:` note, and the geometry must still run where it can: no cells means a solid web. `effective` resolves auto values, runs the checks and returns the notes described in Task 6; for now return the sizes note and the fly note. `bolt_length` is `outer_thickness + outer_z0 + wall_thickness + backing + nut_height + 1 − SINK`, rounded up to stock, where backing is `nut_ledge` or `washer_thickness` on `one_piece`. Rim checks apply only to fixings that have them: head seat `rim/2 ≥ head_d/2 + 0.2 + 1`; wall land `rim/2 − hole_d/2 − collar_wall − collar_fit ≥ 1` with a collar; on `centre_bolt`, `rim ≥ collar_wall + collar_fit + 2`. Outer thickness at least `SINK + (head_d + 0.4 − hole_d)/2 + MIN_LAND`. `area_after_bars > 0`. Printed meshes must have at least one cell and at most `MAX_CELLS`, and `mesh_thickness ≤ outer_thickness`.

- [ ] **Step 3: Implement it**

The approach is proven by a timing test and is not to be replaced by per-cell boolean cuts, which are far slower:

```python
web = Part.Face(stadium_wire(outer_r, s, z0))    # counter-clockwise
web.cutHoles(clockwise_cell_wires)               # in place. Must wind opposite the outline, or the holes aren't cut
web = web.extrude(Vector(0, 0, t))
frame = frame_face_at(z0 + t).extrude(Vector(0, 0, outer_thickness - t))
outer = web.fuse(frame).removeSplitter()
```

Measured this way, defaults take a few seconds and a 100 mm round grid about 20 s, with the result one valid solid. Overlapping the web into the rim instead was slower, and winding the holes the same way as the outline left them uncut and the solid invalid.

Bars and hubs go into the frame layer only. The web runs under them, with no cells there. Cut bolt holes afterwards. When `t == outer_thickness`, skip the frame layer. For `slicer`, the web is the plain outline with no holes. `build_mesh_zone` is the opening's face minus bars and hubs, from z0, height `mesh_thickness`.
